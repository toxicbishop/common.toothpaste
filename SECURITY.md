# Security Policy

## Supported Versions

Since this is an educational tool and personal script, only the latest version of the `common.toothpaste` script is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerability in this project (e.g., related to how Git handles identity credentials or how it interacts with the GitHub API), please do **not** open a public issue.

Instead, please report it privately:
1. Go to the [Security Advisories](https://github.com/toxicbishop/common.toothpaste/security/advisories) tab on this repository.
2. Click **"Report a vulnerability"** to privately disclose the issue to the maintainer.

Alternatively, you can reach out directly to the maintainer via the email associated with the GitHub profile `@toxicbishop`.

I will try to acknowledge your report within 48 hours and provide a timeline for a fix. Thank you for helping keep this tool secure!
